# ML Notes - Mathematics Primer

This repository contains interactive study notes for the Machine Learning course at Hanyang University ERICA (Fall 2026).

## Contents

- `index.html` - Landing page with lecture overview and progress tracking
- `notes/` - Self-contained HTML lecture notes with interactive demos
- `notebooks/` - Jupyter notebooks mirroring the HTML notes
- `requirements.txt` - Python dependencies for the notebooks
- `README.md` - This file

## How to Use

### HTML Notes
1. Open any HTML file in the `notes/` directory directly in your browser
2. No installation required - all HTML notes are self-contained
3. Features interactive demos, worked examples, and practice questions

### Jupyter Notebooks
1. Install dependencies: `pip install -r requirements.txt`
2. Launch Jupyter: `jupyter notebook`
3. Open the desired notebook from the `notebooks/` directory
4. Run all cells to see the full implementation

## Features

- **Interactive Demos**: Vanilla JavaScript visualizations in HTML notes
- **Worked Examples**: Step-by-step calculations with explanations
- **Practice Questions**: Hidden answers for self-testing
- **Video Recommendations**: Curated YouTube search links
- **Cheat Sheets**: Print-ready summary sheets
- **Dark Mode**: Toggleable theme for comfortable viewing
- **Progress Tracking**: Overview of completed lectures

## Lecture Structure

Each lecture follows this format:
1. Big Idea - One-sentence overview
2. Everyday Metaphor - Real-world analogy
3. Why It Matters - Practical significance
4. Formulas - LaTeX-rendered with symbol explanations
5. Worked Example - Hand-calculated problem
6. Interactive Demo - Browser-based visualization
7. Watch Out - Common mistakes and exam traps
8. Experiment Link - Related notebook section
9. Videos - Recommended YouTube searches
10. Practice Questions - Self-assessment with hidden answers
11. Cheat Sheet Draft - Print-ready summary

## Notes

- HTML notes are designed to be printed as cheat sheets (print CSS included)
- Notebooks implement algorithms from scratch before verifying with scikit-learn
- All content is based solely on provided course materials
- No external dependencies beyond standard web technologies for HTML notes
