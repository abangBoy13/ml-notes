Lecture 04: Linear Discriminant and Kernel Machines

Classification boundaries, linear discriminants, and kernel methods for nonlinear separation

Big Idea

Linear discriminant analysis finds optimal linear boundaries between classes, while kernel methods implicitly map data to higher dimensions where linear separation is possible. Together they form powerful approaches to classification that handle both linear and nonlinear patterns in data.

Everyday Metaphor

💡 **Linear Discriminant = finding the best road between towns**: Imagine two towns (classes) scattered across a landscape. Linear discriminant analysis finds the road (boundary) that best separates them while keeping each town on its proper side.
**Kernel Method = teleporting to a mountain view**: Sometimes you can't see a clear separation from ground level. Kernel methods are like teleporting to a mountaintop where the landscape appears different and separation becomes easy.
**Feature Space = different perspectives on data**: The original features give one view of your data. Kernels implicitly compute what your data would look like from other perspectives without actually computing those views.

Why It Matters

  • LDA provides interpretable linear boundaries with probabilistic outputs
  • Kernel methods enable linear algorithms to solve nonlinear problems
  • The kernel trick avoids explicit computation in high-dimensional spaces
  • Foundation for SVMs and other advanced classification techniques
  • Essential for understanding how to handle complex, nonlinear relationships in data

Formulas

$$\\mathbf{w} = \\Sigma^{-1} (\\mu_1 - \\mu_2)$$

LDA weight vector

What each symbol means in LDA:

  • \\mathbf{w}: Weight vector defining the discriminant direction
  • \\Sigma^{-1}: Inverse of covariance matrix
  • \\mu_1, \\mu_2: Mean vectors for each class
  • \\mathbf{x}: Input feature vector
  • b_0: Bias term (incorporates class priors)
  • y = \\mathbf{w}^T \\mathbf{x} + b_0: Discriminant score

$$y = \\mathbf{w}^T \\mathbf{x} + b_0$$

LDA discriminant function

What each symbol means in the discriminant function:

  • \\mathbf{w}^T \\mathbf{x} + b_0: Discriminant function value
  • = 0: Decision boundary where classes are equally likely
  • Points with \\mathbf{w}^T \\mathbf{x} + b_0 > 0 classified as class 1
  • Points with \\mathbf{w}^T \\mathbf{x} + b_0 < 0 classified as class 2

$$K(\\mathbf{x}_i, \\mathbf{x}_j) = \\langle \\phi(\\mathbf{x}_i), \\phi(\\mathbf{x}_j) \\rangle$$

The kernel trick

What each symbol means in the kernel trick:

  • K(\\mathbf{x}_i, \\mathbf{x}_j): Kernel function computing similarity
  • \\phi: Feature mapping to higher-dimensional space (often implicit)
  • \\langle \\cdot, \\cdot \\rangle: Inner product (dot product)
  • The kernel trick computes \\phi(\\mathbf{x})^T \\phi(\\mathbf{z}) without explicitly computing \\phi(\\cdot)

$$K(\\mathbf{x}, \\mathbf{z}) = \\exp\\left(-\\gamma \\| \\mathbf{x} - \\mathbf{z} \\|^2\\right)$$

RBF (Gaussian) kernel

Worked Example by Hand

🧮 Simple LDA: Two classes with means [0,0] and [2,2], identity covariance. Find the discriminant vector and classify point [1,1].

Step 1: Define the problem

Class 1: \\mu_1 = [0, 0]^T

Class 2: \\mu_2 = [2, 2]^T

Shared covariance: \\Sigma = I = [[1,0],[0,1]]

Step 2: Compute the discriminant vector

$$\\mathbf{w} = \\Sigma^{-1} (\\mu_1 - \\mu_2) = I^{-1} ([0,0]^T - [2,2]^T) = [-2, -2]^T$$

Step 3: Compute the bias term (assuming equal priors)

$$b_0 = -\\frac{1}{2} \\mathbf{w}^T (\\mu_1 + \\mu_2) = -\\frac{1}{2} [-2,-2] [0,0]^T + [2,2]^T = -\\frac{1}{2} [-2,-2] [2,2]^T = 4$$

Step 4: Write the discriminant function

$$y = \\mathbf{w}^T \\mathbf{x} + b_0 = [-2, -2] [x_1, x_2]^T + 4 = -2x_1 - 2x_2 + 4$$

Step 5: Classify the point [1,1]

$$y = -2(1) - 2(1) + 4 = -2 -2 + 4 = 0$$

Answer: The point [1,1] lies exactly on the decision boundary (y=0).

With equal priors and symmetric classes, [1,1] is equidistant from both class means.

Watch Out: Common Mistakes & Exam Traps

  • Confusing LDA with logistic regression: Both are linear classifiers, but LDA assumes Gaussian distributions with shared covariance, while logistic regression makes no distributional assumptions.
  • Misunderstanding the kernel trick: Kernels don't explicitly compute \\phi(\\mathbf{x}); they compute inner products \\langle \\phi(\\mathbf{x}_i), \\phi(\\mathbf{x}_j) \\rangle directly.
  • Choosing inappropriate kernel parameters: \\gamma too small -> underfitting, \\gamma too large -> overfitting (similar to bandwidth in density estimation).
  • Forgetting that LDA requires shared covariance: If classes have very different covariances, consider Quadratic Discriminant Analysis (QDA) instead.
  • Overlooking kernel computation cost: While the kernel trick avoids explicit \\phi(\\mathbf{x}) computation, computing the full kernel matrix is still O(n^2) in memory and time.

Practice Questions

❓ Try to solve these yourself first, then check the answers below!

Question 1 (Concept): What is the main assumption of LDA that distinguishes it from logistic regression?

LDA assumes that features follow Gaussian distributions with identical covariance matrices across classes, while logistic regression makes no distributional assumptions about the features.

Question 2 (Concept): What does the kernel trick allow us to do?

The kernel trick allows us to compute inner products in a high-dimensional feature space without explicitly computing the feature mapping, enabling linear algorithms to solve nonlinear problems efficiently.

Question 3 (Calculation): For the polynomial kernel K(\\mathbf{x}, \\mathbf{z}) = (\\mathbf{x}^T \\mathbf{z} + 1)^2, what is K([1,2], [3,4])?

[1,2]^T [3,4] = 1×3 + 2×4 = 3 + 8 = 11
(11 + 1)^2 = 12^2 = 144

Question 4 (Concept): When would you prefer Kernel PCA over standard PCA?

Prefer Kernel PCA when the data has nonlinear structure that cannot be captured by linear combinations of the original features, but becomes linearly separable in some feature space.

Question 5 (Explain it simply): What's the difference between LDA and QDA?

LDA assumes all classes share the same covariance matrix, while QDA allows each class to have its own covariance matrix. LDA produces linear decision boundaries, QDA produces quadratic ones.

Key Definitions

  • Linear Discriminant Analysis: Finds linear combination of features that separates classes
  • Kernel Function: Computes inner product in feature space without explicit mapping
  • Kernel Trick: Uses kernels to enable linear algorithms in high-dimensional spaces
  • Feature Space: Space where data is represented after applying \\phi(\\cdot)
  • Gram Matrix: Matrix of all pairwise kernel values K(\\mathbf{x}_i, \\mathbf{x}_j)

Common Mistakes to Avoid

  • Confusing LDA with logistic regression assumptions
  • Misunderstanding that kernels compute inner products, not explicit mappings
  • Choosing inappropriate kernel parameters (\\gamma)
  • Forgetting LDA's shared covariance assumption
  • Overlooking computational cost of kernel matrices
