Lecture 06: Clustering

Unsupervised learning: finding hidden patterns in unlabeled data

Big Idea

Clustering groups similar data points together without predefined labels, revealing inherent structure in unlabeled data through similarity measures. Unlike supervised learning, clustering discovers patterns organically, making it invaluable for exploratory data analysis and preprocessing.

Everyday Metaphor

💡 **Clustering = organizing a messy desk**: Imagine your desk is covered with various objects. Clustering is like grouping similar items together - pens with pens, papers with papers, etc. - without being told what categories to use.
**Similarity Measure = how we decide what's 'like' what**: The rule we use to determine if two items belong together (e.g., same color, same function, same size).
**Cluster Centroid = the representative of a group**: The average or most typical item in a cluster that represents the group's characteristics.

Why It Matters

  • Discovers hidden patterns in unlabeled data
  • Useful for customer segmentation, image compression, anomaly detection
  • Prepares data for other machine learning algorithms
  • Helps understand data structure before supervised learning
  • Essential for exploratory data analysis

Formulas

$$d(\\mathbf{x}, \\mathbf{y}) = \\sqrt{\\sum_{i=1}^n (x_i - y_i)^2}$$

Euclidean distance

What each symbol means in Euclidean distance:

  • \\mathbf{x}, \\mathbf{y}: Data points in n-dimensional space
  • x_i, y_i: Individual features/coordinates
  • n: Number of dimensions/features
  • \\sqrt{\\cdot}: Square root function
  • \\sum_{i=1}^n: Summation over all dimensions

$$\\arg\\min_{\\mathbf{S}} \\sum_{i=1}^k \\sum_{\\mathbf{x} \\in S_i} \\|\\mathbf{x} - \\boldsymbol{\\mu}_i\\|^2$$

K-means objective function

What each symbol means in the K-means objective:

  • \\mathbf{S} = {S_1, S_2, ..., S_k}: Partition of data into k clusters
  • \\boldsymbol{\\mu}_i: Centroid (mean) of cluster S_i
  • \\|\\mathbf{x} - \\boldsymbol{\\mu}_i\\|: Euclidean distance between point \\mathbf{x} and centroid \\boldsymbol{\\mu}_i
  • k: Number of clusters (chosen in advance)
  • \\arg\\min: Argument that minimizes the function

$$p(\\mathbf{x}) = \\sum_{k=1}^K \\phi_k \\mathcal{N}(\\mathbf{x} | \\boldsymbol{\\mu}_k, \\boldsymbol{\\Sigma}_k)$$

Gaussian Mixture Model

What each symbol means in GMM:

  • p(\\mathbf{x}): Probability density of observing point \\mathbf{x}
  • K: Number of mixture components (clusters)
  • \\phi_k: Mixing coefficient for component k (\\phi_k ≥ 0, \\sum \\phi_k = 1)
  • \\mathcal{N}(\\mathbf{x} | \\boldsymbol{\\mu}_k, \\boldsymbol{\\Sigma}_k): Gaussian distribution with mean \\boldsymbol{\\mu}_k and covariance \\boldsymbol{\\Sigma}_k
  • \\boldsymbol{\\mu}_k: Mean vector of component k
  • \\boldsymbol{\\Sigma}_k: Covariance matrix of component k

Worked Example by Hand

🧮 Simple clustering: Group these 2D points into 2 clusters: [1,1], [1,2], [2,1], [8,8], [8,9], [9,8]

Step 1: Visualize the data

Points form two obvious groups:

Group 1: (1,1), (1,2), (2,1) clustered around (1,1)

Group 2: (8,8), (8,9), (9,8) clustered around (8,8)

Step 2: Apply K-Means with K=2

Initialization: Randomly choose 2 centroids

Let's say we pick C1 = [1,1] and C2 = [8,8]

Step 3: Assignment Step

- Distance from [1,1] to C1: 0, to C2: √98 ≈ 9.9 → Assign to C1

- Distance from [1,2] to C1: 1, to C2: √85 ≈ 9.2 → Assign to C1

- Distance from [2,1] to C1: 1, to C2: √85 ≈ 9.2 → Assign to C1

- Distance from [8,8] to C1: √98 ≈ 9.9, to C2: 0 → Assign to C2

- Distance from [8,9] to C1: √85 ≈ 9.2, to C2: 1 → Assign to C2

- Distance from [9,8] to C1: √85 ≈ 9.2, to C2: 1 → Assign to C2

Step 4: Update Step

- New C1 = mean([1,1], [1,2], [2,1]) = [4/3, 4/3] ≈ [1.33, 1.33]

- New C2 = mean([8,8], [8,9], [9,8]) = [25/3, 25/3] ≈ [8.33, 8.33]

Step 5: Repeat Assignment

All points still assign to same clusters with updated centroids

Step 6: Convergence

Centroids no longer change significantly

Final Clusters:

- Cluster 1: [1,1], [1,2], [2,1] (Centroid ≈ [1.33, 1.33])

- Cluster 2: [8,8], [8,9], [9,8] (Centroid ≈ [8.33, 8.33])

Answer: The algorithm correctly identifies the two natural groups in the data.

Watch Out: Common Mistakes & Exam Traps

  • Assuming K-means finds globally optimal solution: K-means converges to local optimum; results depend on initialization.
  • Ignoring feature scaling: Distance-based clustering is sensitive to feature scales; always standardize features first.
  • Choosing wrong distance metric: Euclidean distance assumes spherical clusters; use Manhattan for high-dimensional sparse data, cosine for text.
  • Misinterpreting hierarchical clustering dendrogram: Vertical height represents distance/dissimilarity, not time or iteration count.
  • Overlooking DBSCAN parameter sensitivity: Results heavily depend on eps and minPts; use k-distance graph to choose eps.
  • Assuming all points must belong to a cluster: DBSCAN and other methods can identify outliers.
  • Using accuracy to evaluate clustering: Accuracy requires true labels; use internal metrics like silhouette score when true labels unknown.
  • Ignoring the curse of dimensionality: Distance metrics become less meaningful in very high dimensions; consider dimensionality reduction first.

Practice Questions

❓ Try to solve these yourself first, then check the answers below!

Question 1 (Concept): What is the main difference between partitioning and hierarchical clustering?

Partitioning clustering (like K-means) divides data into non-overlapping clusters without any hierarchical structure. Hierarchical clustering creates a tree of clusters (dendrogram) showing relationships between clusters at different levels of granularity.

Question 2 (Concept): Why is feature scaling important before clustering?

Clustering algorithms based on distance metrics are sensitive to the scale of features. Features with larger scales will dominate the distance calculation, leading to biased clusters. Standardization ensures all features contribute equally to distance computations.

Question 3 (Calculation): Given two points A(2,3) and B(5,7), what is the Euclidean distance between them?

d(A,B) = √[(5-2)² + (7-3)²] = √[3² + 4²] = √[9 + 16] = √25 = 5

Question 4 (Concept): When would you prefer DBSCAN over K-means?

Prefer DBSCAN when: you want to find arbitrarily shaped clusters, you expect noise/outliers in your data, you don't want to specify the number of clusters in advance, or your clusters have varying densities.

Question 5 (Explain it simply): What does the 'silhouette score' measure in clustering evaluation?

The silhouette score measures how similar a point is to its own cluster compared to other clusters. It ranges from -1 to 1, where high values indicate good clustering (points well-matched to their own cluster and poorly matched to neighboring clusters).

Key Definitions

  • Centroid: The mean position of all points in a cluster
  • Inertia: Sum of squared distances of samples to their closest cluster center
  • Linkage Criteria: Method for calculating distance between clusters in hierarchical clustering
  • Core Point (DBSCAN): A point with at least minPts neighbors within distance eps
  • Noise Point (DBSCAN): A point that is neither a core point nor reachable from a core point
  • Silhouette Score: Measure of how similar an object is to its own cluster vs other clusters

Common Mistakes to Avoid

  • Assuming K-means finds globally optimal solution (finds local optimum)
  • Ignoring feature scaling before distance-based clustering
  • Choosing wrong number of clusters K without validation
  • Misinterpreting hierarchical clustering dendrogram heights
  • Overlooking DBSCAN's sensitivity to eps and minPts parameters
  • Assuming all clustering points must belong to a cluster (algorithms can identify outliers)
  • Using accuracy to evaluate clustering without ground truth labels
  • Ignoring the curse of dimensionality in high-dimensional feature spaces
